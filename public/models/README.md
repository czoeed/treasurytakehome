# PaddleOCR model files

These PP-OCRv5 mobile inference archives are distributed by the official PaddleOCR model repository and loaded from this folder for browser-side inference:

- `PP-OCRv5_mobile_det_onnx_infer.tar` — text-region detection
- `PP-OCRv5_mobile_rec_onnx_infer.tar` — text recognition

Upstream model assets: <https://github.com/PaddlePaddle/PaddleOCR/tree/main/paddleocr-js>

PaddleOCR is Apache-2.0 licensed. The model archives are about 21 MB combined. Label images are processed locally; the app does not upload them to PaddleOCR.
